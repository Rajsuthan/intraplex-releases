# Intraplex for Mac

Turn a Mac you already own into a private AI for your whole team. Chats, files and questions stay on your own Macs and your own network.

**Download:** see [Releases](https://github.com/Rajsuthan/intraplex-releases/releases/latest).

Requires a Mac with Apple Silicon (M1 or later). The app is signed and notarized by Apple.

This repository only hosts release downloads.
